# منصة اختبارات الهندسة الكيمياوية (Apple Style MCQ Platform)

منصة تفاعلية احترافية بتصميم وهوية **Apple** البصرية لاختبارات الاختيار من متعدد (MCQ) لقسم الهندسة الكيمياوية، مصممة للعمل مباشرة عبر **GitHub Pages** أو محلياً.

## هيكلية المجلدات (المواد الدراسية الـ 8)

1. `Principles_of_Chemical_Engineering` — مبادئ الهندسة الكيمياوية
2. `Fluid_Mechanics` — جريان الموائع
3. `Thermodynamics` — الثرموداينمك
4. `Heat_Transfer` — انتقال الحرارة
5. `Mass_Transfer` — انتقال الكتلة
6. `Chemical_Reaction_Engineering` — المفاعلات
7. `General_Questions` — أسئلة عامة
8. `English_Language` — اللغة الإنجليزية

## كيفية إضافة موضوع جديد (ملف JSON)

يمكنك إضافة الأسئلة بطريقتين:
1. **مباشرة عبر GitHub**: ارفع ملف `.json` (مثلاً `Density.json`) داخل مجلد المادة المطلوبة في مستودع GitHub الخاص بك. يقوم الموقع تلقائياً بقراءة محتويات المجلد عبر GitHub API أو عبر ملف الفهرس `manifest.json` وعرضه كبطاقة موضوع احترافية.
2. **مباشرة من داخل واجهة الموقع**: اضغط على زر **"رفع ملف موضوع (JSON)"** داخل صفحة المادة أو اسحب الملف وأفلته ليتم قراءته وإضافته فوراً كبطاقة موضوع.
