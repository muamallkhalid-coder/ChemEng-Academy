نموذج ملف JSON القياسي + البرومبت الجاهز للذكاء الاصطناعي

استخدم البرومبت أدناه مع أي ذكاء اصطناعي (مثل ChatGPT أو Gemini أو Claude) لتحويل أي ملازم أو أسئلة عشوائية إلى ملف JSON متوافق 100% مع موقعك، بحيث يحتوي على اسم الموضوع بالإنجليزية والعربية، السؤال بالإنجليزية وتحته ترجمته العربية، الخيارات الأربعة بالإنجليزية فقط، والشرح المفصل مع ترجمته العربية.

1. البرومبت الجاهز لإرساله للذكاء الاصطناعي (انسخه وألصق أسئلتك معه)

أريد منك تحويل الأسئلة التالية (أو توليد أسئلة اختيارات MCQ في اختصاص الهندسة الكيمياوية) وترتيبها بدقة داخل كود JSON صالح 100% بدون أي نصوص إضافية خارجه، وفق القواعد الصارمة الآتية:

1. كتابة اسم الموضوع باللغة الإنجليزية في الحقل "topic_en" وباللغة العربية في الحقل "topic_ar" ليقوم الموقع بقراءتهما وطباعتهما في بطاقة الموضوع تلقائياً.
2. كتابة اسم مجلد المادة في الحقل "subject_folder" من بين المجلدات الثمانية الآتية:
   - Principles_of_Chemical_Engineering
   - Fluid_Mechanics
   - Thermodynamics
   - Heat_Transfer
   - Mass_Transfer
   - Chemical_Reaction_Engineering
   - General_Questions
   - English_Language
3. لكل سؤال داخل مصفوفة "questions":
   - "question_en": نص السؤال باللغة الإنجليزية.
   - "question_ar": ترجمة نص السؤال إلى اللغة العربية بدقة (تظهر أسفل السؤال).
   - "options": مصفوفة تحتوي على 4 خيارات باللغة الإنجليزية فقط (بدون ترجمة الخيارات).
   - "correct_index": رقم الخيار الصحيح يبدأ من الصفر (0 للخيار الأول، 1 للثاني، 2 للثالث، 3 للرابع).
   - "explanation_en": شرح علمي واضح باللغة الإنجليزية يوضح لماذا هذا الخيار هو الصحيح مع خطوات الحل.
   - "explanation_ar": ترجمة شرح الإجابة إلى اللغة العربية (تظهر أسفل الشرح الإنجليزي).
   - "requires_scratchpad": ضع قيمته true إذا كان السؤال عبارة عن مسألة رياضية تحتاج إلى حل بالقلم في المسودة، أو false إذا كان سؤالاً نظرياً.

استخدم هذا الهيكل القياسي حرفياً:
{
  "topic_en": "Density & Specific Gravity",
  "topic_ar": "الكثافة والوزن النوعي",
  "subject_folder": "Principles_of_Chemical_Engineering",
  "description_ar": "وصف مختصر للموضوع",
  "questions": [
    {
      "id": 1,
      "question_en": "English question text here?",
      "question_ar": "ترجمة السؤال باللغة العربية هنا؟",
      "options": [
        "Option A in English only",
        "Option B in English only",
        "Option C in English only",
        "Option D in English only"
      ],
      "correct_index": 0,
      "explanation_en": "Detailed explanation in English.",
      "explanation_ar": "ترجمة الشرح باللغة العربية لماذا الخيار صحيح.",
      "requires_scratchpad": true
    }
  ]
}
